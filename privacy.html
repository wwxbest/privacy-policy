课境随行（CampusClassFlow）

更新日期：2026年9月7日
生效日期：2026年9月7日

开发者名称：王文学

课境随行（CampusClassFlow）（以下简称“本应用”）是一款由个人开发者提供的课程管理与勿扰模式自动切换工具。我们深知个人信息对您的重要性，并会尽全力保护您的个人信息安全。本隐私政策旨在向您说明本应用如何收集、使用、存储和保护您的个人信息，以及您所享有的权利。

请您在使用本应用前，仔细阅读并充分理解本隐私政策。首次启动时，您可以先阅读政策全文，再主动选择“同意并继续”或“不同意并退出”。阅读政策或返回提示页不会被视为同意。相机、通知、勿扰等权限仍需在相关功能需要时另行授权。

一、我们收集哪些信息

本应用无需注册或登录。课程、学校、学期和提醒等业务数据默认保存在您的设备本地，不自动上传至开发者或第三方云端服务器。您主动使用文件传输、导出或外部链接时的数据处理见下文。我们处理以下信息以提供您选择的功能：

1. 您主动输入或导入的信息

  • 学校信息：学校名称、校区名称。
  • 学期信息：学期名称（如“2025/2026第1学期”）、第1周周一日期、学期总周数。
  • 课程信息：课程名称、星期、节次、周次、教室、班级、班级人数、任课教师。
  • 特殊安排：考试、监考、会议、评标、演出等单次安排的信息（名称、日期、时间）。
  • 提醒事项：待办任务、生日/纪念日等周期提醒的内容、日期、重复规则。
  • 作息方案：夏令/冬令作息时间、课时长度、课间时长等设置。
  • 校历调整：国家节假日跟随设置、调休补课日映射、校级安排（运动会、校庆、考试、临时停课等）。

2. 从课表文件导入的信息

  • 当您通过本应用导入 .xls 或 .xlsx 格式的教师或学生课表文件时，本应用会在本地读取并解析文件中的课程数据（课程名称、星期、节次、周次、教室、班级、任课教师等）。
  • 导入操作仅在本地解析文件，不会自动上传或分享原始文件。如果您另行选择“发送文件”，则会按您的操作传输所选文件。

3. 设备相关信息（本地使用，不上传）

  • 设备型号与系统版本：用于适配不同Android设备的界面显示和功能兼容性。
  • 系统时间与时区：用于正确显示课程时间、计算当前是否处于上课时段。

4. 文件传输、扫码与背景图片

  • 扫码接收：在您主动进入扫码功能并授予相机权限后，应用在本机处理相机预览画面以识别传输二维码，不录制或上传相机画面；离开扫码页面后停止使用相机。
  • 局域网或热点传输：您选择发送或接收文件时，应用使用本机或对端的 IP 地址、临时端口、传输令牌、文件名、文件大小、校验值和文件内容，在设备之间直接传输。发送端会临时提供文件服务，不经过开发者的云端中转服务器。
  • 离线二维码传输：二维码中会包含所选文件的编码内容与校验信息；接收端通过相机识别并在本机还原文件。请仅向您信任的接收方展示传输二维码。
  • 自定义背景：通过系统文件选择器读取您选中的图片及其访问地址，并保存该图片的持续读取授权以供下次显示；不遍历您的相册。更换或移除背景时，应用尝试释放原图片的读取授权。

5. 本地设置与诊断记录

应用保存界面偏好、授权状态相关判断、隐私政策同意版本摘要，以及提醒调度、接收、执行结果和错误信息等本地诊断记录，用于保持您的选择和排查提醒问题。这些记录不自动上传。您通过邮件主动反馈时，我们会收到您的邮箱地址及您发送的文字、附件，仅用于处理反馈与回复。

6. 权限及系统能力

拒绝相机、通知或勿扰等可选权限会影响对应功能，不影响无需该权限的课程查看与编辑。您可以在系统的应用权限或特殊访问权限设置中调整授权。

  • 相机（CAMERA）：仅用于主动发起的二维码扫描；拒绝后无法扫码接收。
  • 通知（POST_NOTIFICATIONS）：用于显示课程和事项提醒；拒绝后相关通知可能无法显示。
  • 精确闹钟（SCHEDULE_EXACT_ALARM / USE_EXACT_ALARM）：用于按设定时间触发提醒和情境切换；不同系统版本的授权方式不同，受限时可能影响准时性。
  • 全屏提醒（USE_FULL_SCREEN_INTENT）：用于您启用的闹钟式提醒；受限时可能无法弹出全屏提醒。
  • 前台服务、媒体播放、唤醒锁和振动：用于在提醒响铃期间维持执行、播放铃声或振动，不用于录音。
  • 开机广播（RECEIVE_BOOT_COMPLETED）：用于设备重启后恢复已设置的提醒和自动计划。
  • 网络访问（INTERNET）：用于您主动选择的设备间文件传输；属于系统安装时授予的普通权限，不会单独弹出授权框。
  • 文件与图片：通过系统文件选择器仅访问您选定的内容；不申请管理全部文件权限。若您选用云端文件提供方，其下载或保存行为由该提供方处理。

勿扰模式（ACCESS_NOTIFICATION_POLICY）：

  • 本应用会请求“勿扰模式”权限，用于根据您的课表自动切换手机的勿扰模式（完全静音、仅震动、仅闹钟、优先打扰等）。
  • 此功能仅在您主动授权后生效，所有切换规则均在本地计算和执行。

二、我们如何使用这些信息

我们根据您选择的功能使用上述信息，用于以下目的：

  • 展示课程表：在“今天”页和“课表”页按日期、学期、学校/校区展示您的课程安排。
  • 自动切换勿扰模式：根据课程时间、特殊安排和您设定的作息方案，在课程开始前自动开启勿扰，在课程结束后恢复。
  • 提醒与通知：在您设定的提醒时间触发通知（待办任务、周期提醒、课程闹钟）。
  • 校历与日期计算：根据学期起始日期、国家节假日规则和您手动调整的校历安排，计算教学周次、放假与补课日。
  • 数据导入与导出：支持从Excel文件导入课表，以及将全部数据导出为JSON备份文件，方便您在不同设备间迁移数据。
  • 文件传输与外观：按您的操作向指定接收设备发送文件、扫码还原文件或显示您选择的背景图片。
  • 桌面小组件：在您添加桌面小组件后，在桌面上显示当天课程概览。

三、信息的存储与安全

  • 存储位置：课程、学期、学校、提醒、作息方案等业务数据及本地设置保存在应用本地存储空间中，在您保留这些数据并使用相应功能期间保存，直至您删除数据、清除应用数据或卸载应用；不自动上传至云端。
  • 数据导出：您可以通过“设置”中的备份功能将数据导出为 JSON 文件，保存位置由您在系统文件选择器中指定；选择云盘或其他外部文件提供方时，请同时了解其隐私规则。导出文件及已传给接收方的副本由您和接收方各自管理。
  • 数据删除：您可以在本应用内随时删除课程、学期、学校等数据；清除应用数据或卸载应用会清除应用私有存储中的数据，但不会自动删除已导出、已另存或已发送到其他设备的文件。
  • 安全措施：应用使用系统私有存储保存业务数据，并关闭系统自动备份。局域网传输采用临时令牌校验，但当前未使用 TLS 加密；文件校验值用于检查完整性，不能代替加密。请在可信的 Wi-Fi 或热点中向可信设备传输，妥善保管设备、二维码和导出文件。任何安全措施都无法保证绝对安全。

四、第三方组件与信息共享

本应用使用以下第三方组件。集成组件不等同于向其开发者上传数据；以下说明限于本应用当前集成的功能。当前没有接入广告、统计分析、云端推送、账号登录或崩溃上报服务。

1. 华为 AppGallery Connect 基础组件

  • 提供方：华为软件技术有限公司。
  • 组件与版本：com.huawei.agconnect:agconnect-core 1.5.2.300，及其异步任务依赖 com.huawei.hmf:tasks 1.4.1.300。
  • 用途与方式：提供应用的华为 AGConnect 本地配置读取、基础实例与组件管理能力；仅在您同意本政策并进入应用后初始化。
  • 处理范围：读取应用包名、随安装包提供的 AGConnect 应用及项目配置等应用信息。当前应用不向该基础组件传入课程、学校、提醒、文件或相机画面，也未集成上述云端业务服务。
  • 参考：AppGallery Connect 官方介绍；华为消费者业务隐私声明（通用声明，具体处理范围以本应用实际启用功能为准）。

2. ZXing 扫码与二维码组件

  • 提供方：JourneyApps 及 ZXing 开源项目贡献者。
  • 组件与版本：com.journeyapps:zxing-android-embedded 4.3.0、com.google.zxing:core 3.5.3。
  • 用途与处理范围：在您主动扫码时通过系统相机接口获取预览画面，在本机解析二维码；发送时在本机将文件或连接信息编码为二维码。相关画面和编码内容不会由本应用上传给组件提供方。
  • 项目说明：JourneyApps 扫码组件、ZXing。

3. JExcelAPI 文件解析组件

  • 提供方：JExcelAPI 开源项目（Andy Khan 及贡献者）。
  • 组件与版本：net.sourceforge.jexcelapi:jxl 2.6.12。
  • 用途与处理范围：在您导入 .xls 课表时，在本机读取所选文件中的单元格、课程和教师等内容，不向组件提供方发送文件或解析结果。.xlsx 文件由应用使用 ZIP/XML 能力在本地解析。
  • 项目说明：JExcelAPI。

4. Lunar 日期换算组件

  • 提供方：6tail（开源项目作者）。
  • 组件与版本：cn.6tail:lunar 1.7.7。
  • 用途与处理范围：使用系统日期或您选择的日期在本机计算公历、农历、节气等信息；不向组件提供方发送日期或提醒内容。
  • 项目说明：lunar-java。

应用还使用 AndroidX、Jetpack Compose 等界面与系统适配基础库，以显示界面、管理生命周期和执行本地功能，不通过这些库主动上报业务数据。

共享与外部访问：开发者不出售您的个人信息，也不自动向第三方提供您的课程和提醒数据。您主动发送文件时，接收设备会获得所选文件。您点击本政策中的外部链接后，将由浏览器访问相应网站，网站可能接收 IP 地址、浏览器信息等访问记录，其处理规则由该网站说明；应用内阅读随安装包提供的政策无需联网。通过邮件联系开发者时，邮件也会经过您与开发者使用的邮件服务提供方。

五、您的权利

作为本应用的用户，您享有以下权利：

  • 知情权：您可以通过本隐私政策了解我们如何处理您的信息。
  • 访问与查看：您可以在本应用内随时查看已录入的所有学校、学期、课程、提醒等信息。
  • 更正与修改：您可以在本应用内随时编辑或修改任何已录入的信息。
  • 删除权：您可以在本应用内删除单条课程、学期、学校等数据；也支持批量删除和一键清理重复记录。
  • 数据导出与迁移：您可以通过“设置”中的备份功能将选定或全部数据导出为 JSON 备份文件，用于备份或迁移至其他设备。
  • 撤回同意：您可以在系统设置中撤销相机、通知、勿扰等功能权限，也可以通过清除本应用数据或卸载本应用撤回全部同意并停止使用。上述操作会清除应用私有存储中的数据与同意记录，无法自动删除已导出或已发送的副本；如仍需保留数据，请先自行备份。重新打开已清除数据的应用时会再次提示阅读本政策。

六、未成年人信息保护

本应用主要面向高校师生，不提供账号注册或年龄识别功能。若您是未成年人，请在监护人的指导下阅读本政策并使用应用；不满十四周岁的用户应在监护人同意后使用。请避免在课程、提醒或传输文件中填写与功能无关的个人信息。监护人可协助您管理、删除设备上的数据，并可通过下述邮箱联系我们。

本隐私政策的最近更新日期为页面顶部所示的“更新日期”。您可随时通过“设置 → 隐私政策”查看安装版本附带的全文。
